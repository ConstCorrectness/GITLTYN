# Project: Grammar is the Last Thing You Need (GITLTYN)
Interactive research publication & ablation suite investigating latent state transitions vs. syntactic token overhead in Small Language Models (SLMs).

## Architecture & Data Contract
- `experiments/`: Python/PyTorch (managed via `uv`) ablation pipelines (Verbose CoT, Telegraphic CoT, Compute-Matched Budget, and Continuous Latent Looping with Lazy Latent Tee probes).
- `web/`: Astro 7 + MDX + React 19 + TypeScript (`.tsx`) + Tailwind CSS v4 + D3.js/Observable Plot interactive article (modeled after OpenEvals Evaluation Guidebook & Epoch AI benchmark explorers).
- `shared/schema.json`: Strict JSON Schema contract shared between Python exporters and TypeScript interfaces (`web/src/types/ablation.ts`).
- **CRITICAL DATA RULE**: NEVER hardcode or fabricate benchmark numbers, model scores, or token traces inside `.tsx`, `.ts`, `.astro`, or `.mdx` files. All visualizations must import schema-validated JSON from `@/data/` (`web/src/data/`) generated by `uv run python experiments/scripts/export_web_artifacts.py`.

## Commands
- **Python Evals & Export**:
  - Run tests: `cd experiments && uv run pytest`
  - Export web JSON: `cd experiments && uv run python scripts/export_web_artifacts.py`
- **Web Interactive Paper (Strictly use `pnpm`, never `npm` or `yarn`)**:
  - Dev server: `cd web && pnpm dev`
  - Typecheck: `cd web && pnpm astro check`
  - Production build: `cd web && pnpm astro check && pnpm build`

## Frontend Engineering Standards (React 19 + TypeScript + Astro)
- All interactive islands in `web/src/components/interactive/` must be written in strict TypeScript React (`.tsx`) using React 19 hooks (`useState`, `useMemo`, `useRef`, `useEffect`).
- Import types and `REGIME_META` colors exclusively from `@/types/ablation`. Never use `any`.
- When mounting Observable Plot or D3 inside React `useEffect`, always clean up DOM nodes in the return function (`return () => plot.remove()`).

## Visual & UI Standards (Epoch AI + Distill Style)
1. **Chart Controls (Epoch Pattern)**: Every quantitative chart in `web/src/components/interactive/` must support:
   - Axis metric switching (e.g., Token Count vs. FLOPs vs. KV-Cache Footprint).
   - Scale toggling (Linear vs. Logarithmic X-axis; Linear vs. Logit Y-axis).
   - Confidence intervals (95% CI shaded bands or error bars on hover tooltips).
   - View toggle between `Graph` and sortable `Table`, plus a `Pareto Frontier Only` filter.
2. **Scrollytelling & Layout (OpenEvals Pattern)**:
   - Keep prose column width strictly at `65ch` for readability; allow interactive figures to bleed to `wide` (`90ch`) or `full-bleed` container widths.
   - Use `<Sidenote>` for tangential proofs/footnotes rather than cluttering main prose.
   - Use consistent semantic color encoding across the entire paper (`REGIME_META`):
     - Verbose CoT (`verbose_cot`): `#64748b` (Slate)
     - Telegraphic CoT (`telegraphic_cot`): `#f59e0b` (Amber)
     - Compute-Matched (`compute_matched`): `#ef4444` (Red)
     - Latent Loop + Tee (`latent_loop`): `#10b981` (Emerald)
     - Latent Tee Sidecar Probe accent: `#6366f1` (Indigo)
3. **Math & Notation Consistency**:
   - Hidden states at layer $L$, step $t$: $h_t^{(L)} \in \mathbb{R}^d$
   - Continuous latent reasoning step $k$: $z_k \in \mathbb{R}^d$
   - Vocabulary unembedding matrix: $W_{\text{unembed}} \in \mathbb{R}^{d \times |V|}$
